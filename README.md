# Swiggy Excel Dashboard

An interactive Excel dashboard analysing Swiggy food delivery data.

## Key Metrics
- Total Sales, Average Ratings, Average Order Value, Rating Count, Total Orders

## Visuals
- Monthly and daily sales trends
- Sales by food type
- State-wise sales map of India
- Top 5 cities by sales
- Weekly trend

## Features
- Slicers for Month, Category and Restaurant Name
- Separate sheets for Dashboard, Analysis and Data

## Tools Used
Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)
